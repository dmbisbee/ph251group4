Simulated Respiratory Disease Outbreak in California

Author

PH251 Group 4

Research Question

How has the simulated respiratory disease outbreak in California progressed over time, which demographic groups and geographic areas are disproportionately affected, and how can these findings guide the allocation of prevention and treatment resources?

race_table <- cases_by_race %>%
  arrange(desc(rate_per_1000)) %>%
  mutate(
    race_eth = case_when(
      race_eth == "White, Non-Hispanic" ~ "White (NH)",
      race_eth == "Black, Non-Hispanic" ~ "Black (NH)",
      race_eth == "American Indian or Alaska Native, Non-Hispanic" ~
        "American Indian or Alaska Native (NH)",
      race_eth == "Asian, Non-Hispanic" ~ "Asian (NH)",
      race_eth == "Native Hawaiian or Pacific Islander, Non-Hispanic" ~
        "Native Hawaiian or Pacific Islander (NH)",
      race_eth == "Multiracial (two or more of above races), Non-Hispanic" ~
        "Multiracial (NH)",
      TRUE ~ race_eth
    )
  ) %>%
  select(race_eth, pop, cumulative_infected, rate_per_1000,
         cumulative_severe, severe_rate_per_1000) %>%
  gt() %>%
  tab_header(
    title = "Recorded infections and severe cases by race/ethnicity",
    subtitle = "California | Reporting weeks dated May 29–December 25, 2023"
  ) %>%
  cols_label(
    race_eth = "Race/ethnicity",
    pop = "2023 population",
    cumulative_infected = "Infections",
    rate_per_1000 = "Infections per 1,000",
    cumulative_severe = "Severe cases",
    severe_rate_per_1000 = "Severe cases per 1,000"
  ) %>%
  fmt_number(
    columns = c(pop, cumulative_infected, cumulative_severe),
    decimals = 0, use_seps = TRUE
  ) %>%
  fmt_number(
    columns = c(rate_per_1000, severe_rate_per_1000),
    decimals = 2
  ) %>%
  cols_align(align = "left", columns = race_eth) %>%
  cols_width(
    race_eth ~ pct(32),
    c(pop, cumulative_infected, rate_per_1000,
      cumulative_severe, severe_rate_per_1000) ~ pct(13.6)
  ) %>%
  tab_source_note(
    "Source: California and Los Angeles morbidity datasets; 2023 population estimates."
  ) %>%
  tab_source_note(
    paste(
      "All ages and both sexes combined. NH = non-Hispanic.",
      "Rates = cases / group population × 1,000; these are crude, not age-adjusted rates.",
      "Rows are ordered by infection rate, highest first. Counts and rates summarize the full study period."
    )
  ) %>%
  opt_row_striping() %>%
  tab_options(
    table.font.names = "Arial",
    table.font.size = px(13),
    table.width = pct(100),
    heading.align = "left",
    data_row.padding = px(9)
  )

Interpretation

The highest crude infection rate was recorded among the non-Hispanic American Indian or Alaska Native group (139.88 per 1,000 residents), while the non-Hispanic White group recorded the highest severe-case rate (4.58 per 1,000) and the largest severe-case count (63,448). Prevention planning can consider groups with higher infection rates, while treatment-capacity planning should consider severe-case counts alongside rates and local service needs.

      "Values represent weekly reported infections."
    )
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(face = "bold", size = 14),
    plot.subtitle = element_text(size = 11),
    axis.title = element_text(face = "bold"),
    plot.caption = element_text(size = 8),
    panel.grid.minor = element_blank()
  ) +
  scale_y_continuous(labels = comma)

Interpretation The epidemic curve shows how the outbreak changed over time, identifying periods of increasing and decreasing transmission. Peaks in the curve represent weeks with the greatest disease activity and can help guide when prevention resources and healthcare capacity were most needed.

Conclusions

The outbreak burden was not evenly distributed across California. Imperial County experienced the highest infection rate, while several racial and ethnic populations experienced substantially higher infection rates than others. These findings suggest that prevention resources should be prioritized toward communities with elevated infection rates and that treatment capacity should be directed toward areas experiencing larger numbers of severe cases.
